# Design_Matrix
Design Matrix For RSM Plot
All information on design matrix is provided in the Design Matrix Info.csv file
All experimental data is provided in Design Matrix data.csv file
Predicted and residual water uptake data is provided in Condition Summary.csv file
95% CI values, t stats and standard error for cubic model is shown in Cubic Coefficient.csv file
Regression anova of cubic model is shown in Regression Anova.csv file
