# Design_Matrix
Design Matrix For RSM Plot
All information on design matrix is provided in the Design Matrix Info.csv file
All experimental data is provided in Cubic_RSM_Design_Matrix.csv file
Predicted and residual water uptake data is provided in Condition_Summary.csv file
95% CI values, t stats and standard error for cubic model is shown in Cubic_Coefficient.csv file
Regression anova of cubic model is shown in Statistical Analysis.csv file
AT RH=0, the uptake was predicted as zero theoretically rather than an experimental value
